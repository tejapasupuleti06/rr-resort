# R R Gardens & Villa Resort — Website

A responsive React + Vite website concept using the original property photographs supplied in the conversation and the Ivory Champagne Luxury design direction.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in Terminal / PowerShell.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite (usually http://localhost:5173).

## Before publishing

Open `src/config.js` and add the verified business phone number, WhatsApp number, full address, Google Maps URL and social links. The enquiry form is intentionally not wired to a made-up number.

Also verify the guest capacity and all amenities with the property management. The displayed 500–1,000 capacity is based on the project brief and should be confirmed for each event layout.
